# Zero Hunger Movement App

A backend application developed using **ASP.NET Core** to support the Zero Hunger initiative.

## Technologies Used
- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- 3-Tier Architecture


## Project Architecture
- **ApiAppLayer:** Handles API requests and responses.
- **BLL:** Manages business logic.
- **DAL:** Handles data access operations.
## Functional Requirements

- **User Management:** Manage application users and their information.
- **Food Management:** Add, update, view, and manage available food items.
- **Restaurant Management:** Maintain restaurant information and records.
- **Food Collection Requests:** Create and manage requests for collecting donated food.
- **Food Distribution:** Manage food distribution activities and records.
- **Employee Management:** Maintain employee information and assignments.
- **Request Tracking:** Track food collection requests and their status.
- **Data Management:** Store, retrieve, update, and delete application data through structured data access operations.
